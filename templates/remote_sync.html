How Remote Sync Works

Match Timer Synchronization:
  • When you click "Start Match on All Systems":
    1. Broadcast a start command to all connected client nodes
    2. Optionally start the match timer locally (controlled by checkbox)
    3. All selected timers start simultaneously across all systems
  • Exclude Master Option: Check the box to only start client matches, leaving the master as a control node
  • Important: Each instance runs its own matches independently
  • The timer synchronization only controls WHEN matches start, not which match is running
Configuration:
  • Master Node (this instance):
    • Set RemoteSyncApiKey to a shared secret
    • Leave RemoteSyncUrl empty
  • Client Nodes:
    • Set RemoteSyncUrl to http://master:9080/api/fll
    • Set the same RemoteSyncApiKey as the master
Score Synchronization:
  • FLL scores are automatically synchronized between nodes
  • When you commit a match result, scores are sent to all connected systems
  • You can manually review and edit scores in the FLL Review page
